🏨 Hostel Room Allocation System

A complete web-based Hostel Room Allocation System that automates student registration, room allotment, availability tracking, admin management, and real-time dashboard statistics.
Built with a modern UI, authentication system, admin panel, chatbot assistant, and live room allocation logic.

📌 Project Overview

Manual hostel room allocation is slow, error-prone, and difficult to manage.

This system provides:
Automated student registration & login
Live room availability tracking (OMV & BH-2 blocks)
Automatic room allotment by admin
Student dashboard with allocation status
Profile management
Dark/Light theme switcher
Built-in chatbot assistant for help

Admin panel for monitoring registrations and allotments

🚀 Key Features
👤 Student Side

Login & Sign Up system

Room registration with preferences
Real-time room availability view
Dashboard with live allocation stats (donut charts)
Allotment result page
Profile editing
Logout system

🧑‍💼 Admin Side

View all student registrations
Run automated room allotment
View all allotted rooms

🤖 Smart Assistant

Chatbot for hostel-related queries
Guides users on registration, status, rooms, profile, etc

🎨 UI Enhancements

Dark / Light mode toggle
Responsive layout
Clean dashboard cards & stats
